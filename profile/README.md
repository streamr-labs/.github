# Streamr Labs

Programmable, real-time payment streams on Stellar

Continuous payouts and recurring subscriptions for stablecoins — defined once, enforced by contract.

## Why Streamr

- Per-second rates — multi-recipient streams with the math handled on-chain
- Subscriptions — escrowed balances with due-date enforcement and automated charge flows
- Instant withdrawal — recipients pull accrued balances with on-chain proofs and auditability
